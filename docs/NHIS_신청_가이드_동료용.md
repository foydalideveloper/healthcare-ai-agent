# NHIS 표본코호트DB 신청 가이드
## (주)트리플에이치 헬스케어 AI 프로젝트용

> **담당자에게**: 이 문서는 헬스케어 AI 에이전트 프로젝트의 LSTM 딥러닝 모델 훈련을 위해
> 국민건강보험공단의 표본코호트 데이터를 신청하는 절차를 안내합니다.

---

## 1. 신청 사이트

**국민건강보험 빅데이터 플랫폼 (NHISS)**
- URL: https://nhiss.nhis.or.kr
- 고객센터: 033-736-2431~5

---

## 2. 회원가입 (먼저 해야 함)

1. https://nhiss.nhis.or.kr 접속
2. 우측 상단 **회원가입** 클릭
3. 본인인증 진행 (공인인증서 또는 휴대폰 인증)
4. 회원정보 입력:
   - **성명**: 본인 이름
   - **소속**: (주)트리플에이치 / Triple-H Co., Ltd.
   - **직위**: 연구원 / 개발자
   - **이메일**: 회사 이메일
   - **연락처**: 본인 휴대폰 번호
5. 가입 완료

---

## 3. 신청할 데이터

### 우리가 필요한 데이터:

| 데이터명 | 설명 | 용도 |
|---------|------|------|
| **표본코호트DB 2.0** | 100만명 대상, 2002~2019년 건강검진+진료+처방 데이터 | LSTM 시계열 예측 모델 훈련 (핵심 데이터) |
| **건강검진코호트DB** | 51.4만명, 건강검진 결과 중심 | 건강 지표 정상/경고/위험 범위 검증 |

### 우리가 사용할 주요 변수:

**건강검진 데이터:**
- BMI (체질량지수)
- 수축기/이완기 혈압 (SBP/DBP)
- 공복혈당 (fasting glucose)
- 총콜레스테롤, HDL, LDL, 중성지방
- 혈색소 (hemoglobin)
- 크레아티닌 (creatinine)
- AST, ALT, GGT (간기능)
- 허리둘레, 체지방률

**인구사회학적 데이터:**
- 성별, 연령, 소득분위
- 장애 여부
- 거주 지역

**진단 이력:**
- ICD-10 질병코드 (당뇨, 고혈압, 심혈관질환 등)

## 4. 신청 절차 (단계별)

### Step 1: 로그인
- https://nhiss.nhis.or.kr 접속 → 로그인

### Step 2: 데이터 신청 페이지 이동
- 상단 메뉴: **연구과제** → **데이터 신청** → **신청하기**

### Step 3: 연구과제 등록
신청 시 연구과제 정보를 입력해야 합니다. 아래 내용을 참고하세요:

#### 연구과제명 (한글):
```
생성형 AI 기반 자율형 헬스케어 시스템의 건강 상태 예측 모델 개발
```

#### 연구과제명 (영문):
```
Development of Health Status Prediction Model for Generative AI-Based Autonomous Healthcare System
```

#### 연구 목적:
```
본 연구는 (주)트리플에이치가 출원한 '생성형 인공지능 기반 자율형 헬스케어 시스템' 
특허(출원번호: 10-2025-0145274)의 상용화를 위해, 시계열 딥러닝 모델(LSTM-Transformer)을 
활용한 건강 상태 예측 알고리즘을 개발하고자 합니다.

구체적으로:
1. 건강검진 시계열 데이터를 기반으로 미래 건강 상태를 예측하는 딥러닝 모델 훈련
2. 인구집단별(연령, 성별, 소득수준) 건강 지표의 정상/경고/위험 범위 검증
3. 디지털 트윈 비교를 위한 표준 건강관리 모델(역할모델) 구축
4. 질병 위험도 가중치 산출 (당뇨, 심혈관질환, 고혈압, 비만 등)

본 데이터는 통계분석 목적으로만 사용되며, 개인정보 보호법을 철저히 준수합니다.
```

### Step 4: 분석 방법 선택

**가상화 연구분석** 을 선택하세요 (원격 분석 가능):

- **가상화분석센터**: 원격으로 접속하여 분석 가능
- 운영시간: 월~금 09:00~18:00
- 접속 방법: 보안프로그램 설치 후 원격 데스크톱 접속

> 참고: 원시데이터 외부 반출은 불가하며, 분석 결과(통계표, 모델 파라미터)만 반출 가능합니다.

### Step 5: IRB (연구윤리심의) 관련

- NHIS 데이터는 **이미 비식별화** 되어 있어 IRB 면제가 가능한 경우가 많습니다
- 하지만 기관에 따라 IRB 심의 또는 면제 확인서가 필요할 수 있습니다
- 만약 IRB가 필요하면: 소속 기관의 IRB 위원회에 면제 신청 가능
- IRB 면제 사유: "공공데이터를 활용한 2차 분석으로, 개인식별정보가 포함되지 않은 비식별화된 데이터 활용"

### Step 6: 제출 및 승인 대기

1. 모든 정보 입력 후 **제출** 클릭
2. 승인까지 약 **2~4주** 소요
3. 진행 상태 확인: 로그인 → **나의 과제** → **MY서비스**
4. 승인 완료 시 이메일/문자 알림

## 5. 승인 후 데이터 분석 방법

### 가상화분석센터 이용:
1. 로그인 → **가상화연구분석** → **PC예약신청**
2. 보안프로그램 다운로드 및 설치
3. 예약된 시간에 원격 데스크톱으로 접속
4. 제공된 데이터(SAS/CSV)를 분석센터 내에서 분석
5. 분석 결과만 반출 신청 (원시데이터 반출 불가)

### 우리가 필요한 결과물:
분석센터에서 아래 작업을 수행한 후 **결과물만 반출** 하면 됩니다:

```
1. 전체 데이터를 CSV로 추출 (비식별화된 상태)
   - 연도별 건강검진 결과 (개인ID, 검진연도, BMI, 혈압, 혈당, 콜레스테롤 등)
   - 인구사회학적 정보 (성별, 연령대, 소득분위)
   
2. 통계 요약표 (반출용)
   - 연령대/성별별 건강지표 평균 및 표준편차
   - 질병 유병률 통계
   - 건강지표 간 상관관계 행렬
   
3. 모델 훈련용 전처리 데이터
   - 시계열 포맷: [개인ID, 연도, 건강지표들...] 
   - 결측치 처리 완료
   - 정규화(normalization) 적용
```

> **중요**: 원시데이터 자체는 반출 불가이므로, 분석센터 내에서 모델 훈련을 하거나,
> 비식별화된 통계 결과물만 반출해야 합니다.
